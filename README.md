# Emissions Tracker Dashboard

## Project Overview
This project analyzes Apple's carbon emissions data to extract meaningful sustainability and business insights using Power BI and DAX. It focuses on emissions trend analysis, scope-based breakdown, product-level carbon footprint comparison, and financial normalization against revenue and market cap.
The system transforms raw sustainability and financial data into an interactive dashboard that supports transparent, data-driven ESG reporting.

## Tools & Technologies
- Power BI Desktop
- DAX (Data Analysis Expressions)
- Power Query

## Dataset
- Greenhouse Gas Emissions Dataset
- Normalizing Factors Dataset (Revenue, Market Cap, Employees)
- Carbon Footprint by Product Dataset

## Workflow
1. Collected and integrated three raw sustainability and financial datasets
2. Cleaned and validated data, identifying null patterns and reporting-scope gaps
3. Built relationships across emissions, financial, and product tables
4. Wrote custom DAX measures for:
    - Gross and Net Emissions
    - Scope 3 totals and offsets
    - Emissions normalization ratios
5. Verified every headline insight directly against raw data before finalizing
6. Designed 4 report pages with purpose-built visuals (waterfall, scatter, treemap, line, pie)
7. Applied consistent styling (rounded corners, custom titles, unified theme) across all pages
8. Developed a final insights panel summarizing key sustainability findings

## Key Features
- Gross vs. Net Emissions tracking with offset impact visualization
- Scope-based emissions breakdown (Scope 1/2/3)
- Product-level carbon footprint comparison
- Emissions normalization against market cap and employee count
- Verified, data-backed insights panel
- Interactive Power BI dashboard across 4 focused pages

## Outcome
Developed a complete Power BI dashboard that reveals Apple's emissions are overwhelmingly Scope 3 (99.8%) and product life cycle-driven (98.8%), while showing emissions intensity relative to market cap has fallen 87% since 2015 — demonstrating environmental efficiency improving faster than raw emissions numbers alone suggest.
